# 📄 AI Resume Analyzer

An AI-powered resume analysis web application built using Python and Streamlit.

The application analyzes a candidate's resume, calculates an ATS score, identifies skills, compares the resume with a job description, recommends courses for missing skills, and generates a professional PDF report.

---

## 🚀 Features

- 📄 Resume PDF Upload
- 🔍 Resume Text Extraction
- 👤 Candidate Information Extraction
- 🛠️ Skill Extraction
- 🎓 Education Analysis
- 📜 Certification Analysis
- 📊 ATS Resume Score
- 💡 Resume Improvement Suggestions
- 📋 Resume Section Analysis
- 🎯 Job Description Matching
- ❌ Missing Skill Detection
- 📚 Course Recommendations
- 🤖 AI Resume vs Job Analysis
- 📄 PDF Resume Report
- 📊 Resume Dashboard
- 🕘 Resume History

---

## 🛠️ Technologies Used
